# FileFlow Project Roadmap

## 🎯 Current Phase: V9.2 "The Cognitive Core"
**Focus**: Benchmarking, Precision Classification, and Semantic Memory.
- [x] **Local LLM Benchmarking**: Auto-select the best model for your hardware.
- [x] **Semantic Memory**: Search files by "meaning" using Vector DB.
- [x] **Vision Layer**: Understanding scanned Z83s and certificates via Ollama.
- [x] **Forensic Auditing**: Level 2 "Scout Reports" for deep folder analysis.

---

## 🚀 Future Phase: V10 "The Colleague Mode" (Cognitive OS)
**Focus**: Transforming FileFlow from a utility into an interactive digital colleague.

### 1. Interactive Staging (The ThinkingApp)
- [ ] **Glass Box Interface**: A UI that shows the AI's "Chain of Thought" in real-time.
- [ ] **Suggestion Cards**: Interactive file moves with "Approve" and "Dismiss" buttons (as seen in V2 designs).
- [ ] **Natural Language Interaction**: "Hey FileFlow, find my bar exam prep and put it in /Education."

### 2. Autonomous Reasoning
- [ ] **Self-Correcting Extraction**: If a reference number format looks wrong, automatically retry with a different vision strategy.
- [ ] **Recursive Discovery**: "Scout" deep hierarchies and suggest structural improvements to the entire archive.
- [ ] **Cross-Document Context**: Understanding that 10 different files are part of one "Job Application Package."

### 3. Advanced Tools
- [ ] **Milestone Planner**: A visual timeline of every archive step before it happens.
- [ ] **Versioned Archiving**: Storing multiple versions of work (e.g., job application drafts) with AI-powered diffing.
- [ ] **Resource Budgeting**: Low-power "Watch Mode" that stays quiet in the background while you work/game.
